# Security policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use GitHub's
private vulnerability reporting feature for this repository instead. Include the
affected version, reproduction steps, impact, and any suggested mitigation.

Do not include real passwords, session secrets, database URLs, access tokens, or
personal data in a report. Revoke and rotate any credential that may have been
exposed; deleting it from the latest commit is not sufficient once it has been
pushed.

## Supported versions

Security fixes are applied to the latest revision of the default branch.
